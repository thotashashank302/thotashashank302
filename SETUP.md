# Green Screen profile: setup and maintenance

Complete this checklist in the profile repository at
`github.com/thotashashank302/thotashashank302`.

## 1. Create the telemetry token

- [ ] Open **GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)**.
- [ ] Select **Generate new token (classic)**.
- [ ] Enable only the `read:user` scope. Public data is sufficient; `repo` is not required.
- [ ] Copy the token when GitHub shows it. Codex cannot create or recover this token for you.
- [ ] Open the profile repository → **Settings → Secrets and variables → Actions → New repository secret**.
- [ ] Set the secret name to `TELEMETRY_TOKEN`.
- [ ] Paste the copied token as the secret value and save it.

The default `GITHUB_TOKEN` can be unable to read the GraphQL
`contributionsCollection` field, so the telemetry workflow uses this dedicated
read-only token.

## 2. Enable workflow write permissions

- [ ] Open the profile repository → **Settings → Actions → General**.
- [ ] Under **Workflow permissions**, select **Read and write permissions**.
- [ ] Save the setting.

Both workflows commit generated files back to the repository, so write access
is required.

## 3. Populate the assets once

- [ ] Open the repository **Actions** tab.
- [ ] Select **Update Mission Telemetry** → **Run workflow** → **Run workflow**.
- [ ] Select **Generate Contribution Snake** → **Run workflow** → **Run workflow**.
- [ ] Confirm that the runs succeed and that the repository contains:
  - `assets/telemetry.svg`
  - `assets/snake-dark.svg`
  - `assets/snake-light.svg`

## Refresh schedule

- Mission Telemetry refreshes daily at `03:17 UTC`.
- Contribution Snake refreshes every six hours.
- Both workflows can also be run manually with `workflow_dispatch`.

The telemetry card and snake use a black and green palette. The telemetry
generator uses only Python's standard library. Run its offline checks with:

```sh
python -m unittest discover -s tests -v
```

## How the Green Screen README works

GitHub displays the root `README.md` because this public repository has the
same name as its owner. Markdown supplies the text, links, headings, table,
and collapsible concept note; self-contained SVG images supply the terminal
visuals. GitHub README content cannot depend on custom page JavaScript or CSS.

- `assets/green-screen.svg` and `assets/green-screen-mobile.svg`: personalized identity panels. Its ASCII portrait
  comes from the free GitSkins Matrix system-scan output for this public
  profile, retrieved on 2026-10-23. Text is customized in the SVG, with no
  changing statistics in this static panel. Edit its profile rows directly
  when skills or projects change. Portrait and text remain visible without
  animation; the moving scan respects reduced-motion preferences.
- `assets/telemetry.svg`: generated from public GitHub data. The UTC update
  date appears in the card. Repository count includes forks; star totals and
  language code volumes exclude forks. The previous snapshot remains in the
  repository if a refresh fails. The generator does not silently publish
  partial language totals when a request fails.
- `assets/snake-dark.svg` and `assets/snake-light.svg`: generated by the
  existing snake workflow. Colors in the workflow match the checked-in SVGs.
- The previous banner and section assets are retained for easy reuse.

No GitSkins account, paid plan, or runtime GitSkins image request is required
to display this adaptation. Links and project descriptions remain ordinary
Markdown so visitors can read and use them on smaller screens.
